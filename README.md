# 小 Clawd 的 Java 大陆

像素风 Java 闯关网站。读取「Java Backend｜00 学习状态卡」，每 2 分钟自动同步：
学习卡里多一个 Level 3，地图上就多一面绿旗，小 Clawd 跟着升级。

```
浏览器（GitHub Pages 上的 index.html）
   │  每 2 分钟 fetch
   ▼
Google Apps Script（以你的身份读取学习卡，只返回游戏需要的行）
   │
   ▼
Google Docs：00 学习状态卡
```

## 第 1 步：部署 Apps Script（约 5 分钟）

1. 打开 https://script.google.com ，点「新项目」
2. 删掉默认代码，把 `apps-script.gs` 的全部内容粘进去，保存
3. 点右上角「部署」→「新建部署」→ 类型选「Web 应用」
4. 「执行身份」选**我**，「谁可以访问」选**任何人**，点「部署」
5. 第一次会要求授权读取 Google 文档，选你的账号并允许
6. 复制得到的网址（以 `/exec` 结尾）

> 「任何人」的意思是：拿到这个网址的人能读到脚本返回的内容。
> 脚本只返回知识点、抖点、每日计划这些行，不包括求职目标、城市和薪资。
> 不要把这个网址提交到 GitHub。

## 第 2 步：放到 GitHub Pages（约 5 分钟）

1. 在 GitHub 新建仓库，比如 `clawd-quest`
2. 把 `index.html` 传上去（`apps-script.gs` 和 README 也可以一起传，它们不含秘密）
3. 仓库 Settings → Pages → Source 选 `main` 分支、`/ (root)`，保存
4. 一两分钟后网站地址是 `https://<你的用户名>.github.io/clawd-quest/`

## 第 3 步：连接学习卡

打开网站，点左上角的 ⚙，粘贴第 1 步的 `/exec` 网址，点「开始冒险」。
网址只保存在这台浏览器里。换设备时再粘贴一次，或者打开：

```
https://<你的用户名>.github.io/clawd-quest/?src=<你的 /exec 网址>
```

## 修改学习卡格式时

游戏靠这些开头来识别内容，老师改格式时这里也要跟着改：

| 学习卡里的写法 | 游戏里的作用 |
|---|---|
| `知识点｜名称｜Level 3…` | 关卡状态（Level 3 及以上＝通关） |
| `已知抖点：A；B` | 扣血，每个抖点 −5 |
| `抽点记录：…闭卷复习…` | 回血，每次 +10 |
| 证据里的「全对」 | 回血，每次 +5 |
| `计划·周X：…` | 今天的关卡任务 |

关卡顺序在 `index.html` 的 `CURRICULUM` 里，按 05 课程地图排列。
